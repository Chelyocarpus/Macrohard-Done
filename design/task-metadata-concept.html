      Four rules behind the layout

      • Group by the question it answersWhen (due, reminder, repeat), progress (steps, note), where (list, tags). A divider between the groups (hairline, dot or outlined capsule: switch above) lets the line read in three glances instead of one long run.
      • Colour only where it means somethingOverdue red, today blue, important amber, done green. Everything else stays in muted grey. Tags and lists keep their own colour as small accents.
      • Detail grows with space, never with noiseCompact uses icons and short words. Comfortable spells them out and adds the note preview. Peek shows every field, including created and edited.
      • A set value is never hidden behind hoverMy Day, important and pinned stay visible once set. Hover only adds the buttons that are still off.
